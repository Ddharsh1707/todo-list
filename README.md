# To-Do List

Add, complete and delete tasks. Tasks are saved in your browser.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/todo-list.git
```
